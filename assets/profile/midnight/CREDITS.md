# Midnight Curiosity assets

Black cat artwork: generated for Logesh using the built-in image_gen tool.
Rooftop scenery and pixel lettering: original work assembled with those sprites.

Brand and technology icons: [Devicon](https://github.com/devicons/devicon), commit
`7330accdbc47e2dc0c19789a48533c4a3c50fe58`. See `DEVICON-LICENSE.txt`.
GitHub and Three.js dark shapes are recolored for contrast.

Utility icons: [Lucide](https://lucide.dev), ISC license, `LUCIDE-LICENSE.txt`.

Contribution calendar: [github-profile-3d-contrib](https://github.com/yoshi389111/github-profile-3d-contrib),
commit `9e3f937195cf840d364388973f73e3c4b3753586`.
See `CONTRIBUTION-RENDERER-LICENSE.txt`.
